Keywords and field names can use either case. Match text values exactly: 'Monday'. Use commas between fields. A final semicolon is optional here.

SQL help
SELECT Club, Day
FROM Clubs
WHERE Places >= 4;
Use * for all columns. Text values need single quotes; numbers do not. Use = for equality. AND needs both conditions; OR needs at least one. Repeat the field in each condition.
Supported here: SELECT, FROM, WHERE, =, !=, <>, <, >, <=, >=, AND, OR, NOT and brackets. This is a small read-only practice evaluator, not a full database. Sorting, LIKE, joins and changes to data are outside this tool.

What does the ? mean?
The ? is a placeholder for a value. Python supplies the value separately using (day,). The comma makes it a one-item tuple. Keep the ? outside quotes. This is a useful Python pattern, not extra SQL syntax to memorise for this lesson.
Open the downloaded file in a Python 3 editor such as IDLE or Thonny and run it. It uses the standard sqlite3 module and a temporary database in memory; no separate database setup is needed.

Teacher notes, scope & saved work
Based on Raspberry Pi GCSE 2024, Unit 7 Programming, T7 Introduction to SQL, worksheets and homework. Uses a new fictional table to reduce reading load. Core scope follows OCR J277 2.2.3: SELECT, FROM and WHERE to search data, with comparisons and simple Boolean conditions.
The supplied slides include ORDER BY, LIKE and other extensions. These are omitted from the main path. The practice evaluator is a limited read-only SQL subset: one Clubs table, selected fields or *, comparisons, AND/OR/NOT and brackets. Text comparisons here are case-sensitive; keywords and identifiers are not. AND binds before OR; use brackets to make mixed conditions clear. No NULL values or joins. Results are displayed in source order for this lesson; SQL does not guarantee row order without ORDER BY.
